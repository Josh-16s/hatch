# $HATCH

One-page narrative site for **$HATCH** — a memecoin culture mark for the act of launching. Launchpads became the dominant memecoin business; this page tells that loop without claiming utility, revenue, or affiliation with any pad.

## Stack

- Next.js (App Router) + TypeScript
- Tailwind CSS
- shadcn/ui

## Run locally

```bash
npm install
npm run dev -- --port 43127
```

Open [http://127.0.0.1:43127](http://127.0.0.1:43127).

## Notes

- No wallet connect, auth, or database.
- Launch CTA is a placeholder until a real URL exists.
- Reference links (pump.fun, bonk.fun, believe.app) are cultural “inspired by” citations only — not partnerships.
